# Flutter WiFi Detector (Demo)

مشروع تجريبي لواجهة تطبيق Flutter مشابهة للصورة التي أرسلتها - باللغة العربية (RTL).
يحتوي على شاشات: الرئيسية، إعدادات الشبكة، التقارير، الهجمات، الإحصائيات، الإعدادات.
يستخدم مكتبة `fl_chart` لرسوم بيانية و`flutter_local_notifications` كعنصر إشعار محلي (مكان مخصص للتهيئة الحقيقية).

## تشغيل المشروع
1. انسخ المجلد إلى جهازك أو حمّل ZIP ثم فك الضغط.
2. شغّل `flutter pub get`
3. افتح المشروع في Android Studio أو VS Code وشغّل على محاكي/جهاز حقيقي.

> ملاحظة: الإشعارات الفعلية ودمج ESP32 تحتاج إعداد إضافي (Firebase أو برتوكول خاص)، هنا وُضعت مكان للتكامل لاحقًا.
